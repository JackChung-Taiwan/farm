# 智耕小塔｜智在家鄉 AI 農業助理平台

這是一個可直接上傳 GitHub Pages 的智慧垂直農業展示網站。

## 內容
- 首頁提案頁
- App Demo 互動範例
- 即時影像監控 Demo
- AI 影像分析示意
- Open Data、IoT、AI 農業助理功能說明
- 產品圖片
- 功能海報
- 三頁漫畫功能解說
- 適用場域圖卡

## 上傳 GitHub Pages
1. 建立 GitHub Repository
2. 上傳本資料夾所有檔案
3. 進入 Settings → Pages
4. Source 選 main branch / root
5. 等待部署完成即可取得網址

## 可修改位置
- `index.html`：網站文字與區塊
- `style.css`：版面與視覺風格
- `script.js`：App Demo 互動邏輯
- `assets/`：產品圖、海報與漫畫圖片
